# 🃏 ♠️ Python Blackjack Game ♥️ ♣️

A classic, interactive terminal-based Blackjack game built completely from scratch in Python! This project delivers an engaging experience complete with custom ASCII art card designs, intelligent Ace handling, and robust game logic. 🎲🚀

---

## ✨ Features

- 🎮 **Interactive Gameplay**: Play full rounds of Blackjack directly from your terminal against a computer dealer.

- 🎨 **Custom ASCII Art Cards**: Beautiful visual representations for cards ranging from Ace to King, complete with custom suit graphics and face card designs.

- 🧠 **Smart Ace Handling**: Intelligent calculations that automatically adjust Ace values between 1 and 11 depending on the player's or computer's hand.

- ⚡ **Smooth Atmosphere**: Includes tailored delays and clean terminal formatting to give you an authentic table experience.

---

## 🧠 Game Logic

- The game manages a loop for dealing cards, checking user choices (`hit` or `stand`), evaluating the dealer's automated moves (drawing up to 17), and finally comparing scores to determine the winner based on standard Blackjack rules.

---

- Designing and structuring a complete multi-file or modular script using Python loops, conditionals, and functions.
- Managing random choices and deck simulations within a terminal environment.
- Handling edge cases such as Ace value adjustments and Bust conditions.
